# Docs

Project notes, architecture diagrams, and visual assets.

- `demo_screenshots/`: screenshots of the current frontend scoring viewer.
- `piano_music/`: the MIDI song library the frontend/orchestrators pick songs from (`docs/piano_music/*.mid` -- see `edge/practice_server.py`'s `SONG_LIBRARY_DIR`).
- `VALIDATION_GUIDE.md`: 给不熟悉这个项目的组员看的一键验证脚本使用说明（`scripts/validate_recording.sh`），录真人弹奏 + 跑评分 + 看结果，不需要碰任何 CLI 参数。
