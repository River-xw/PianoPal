# Result posture GIFs

These GIFs are shown in the final report when the motion score is below 80.
The viewer selects the most frequent non-`normal` label from
`summary.motion_assessment.label_counts` and displays it beside `normal.gif`.

Model label to file mapping:

- `finger_collapse` → `figure_collapse.gif`
- `high_lift_tap` → `high_lift_tip.gif`
- `wrist_arch` → `wrist_arch.gif`
- `wrist_collapse` → `wrist_collapse.gif`
- `wrist_shake` → `wrist_shake.gif`
- correct reference → `normal.gif`
