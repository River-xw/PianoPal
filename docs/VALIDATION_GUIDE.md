# 录音验证评分算法指南

## 为什么需要这份验证

目前评分算法（`reference-dtw` 模式，能吸收真人弹奏中途变速/rubato，取代了旧的 `reference-grid` 线性对齐）所有测试都是用**真实电子琴音色、但程序合成出来的演奏**——声音是真的 BF-3738C 录音样本，但弹奏的节奏、音符时间点是照 MIDI 精准对齐的，没有真人弹奏会有的节奏浮动、弹错、环境杂音。这一步验证需要**真人实际弹这台电子琴的录音**，才能确认算法在真实情况下准不准。

不需要懂算法细节，也不需要打指令，照下面步骤做就可以。

## 前置需求

- 这台 BIGFUN BF-3738C 电子琴（37键）
- 录音设备（手机录音、笔记本麦克风都可以，正常环境音量、不用特别安静的房间，但避免同时有其他人讲话/音乐）
- 这个 repo 已经 clone 下来，且 `backend/audio_to_performance/.venv` 这个虚拟环境已经建好（如果没有，看 `backend/audio_to_performance/README.md` 的安装说明）

## 第一步：录音

先从下面 5 首里选一首（**只能选这 5 首**，因为只有这 5 首完全落在这台琴的22个白键范围内，其他歌曲需要黑键，工具还不支持）：

- 小星星 (twinkle_twinkle)
- 十个小印第安人 (10_little_indians)
- Alabama（唯一有双手的）
- 帕赫贝尔卡农 (pachelbel_canon)
- 平安夜简易版 (silent_night_easy)

想看谱可以用任何 MIDI 播放器打开 `docs/piano_music/` 里对应的文件，或跟我要谱子截图。

录 **两个版本**，分开存成两个录音档：

1. **尽量弹对的版本**：从头到尾照谱弹一次，尽量不要弹错、尽量照着正常节奏弹。
2. **故意弹错几个音、或某几个地方明显抢拍/拖拍的版本**：故意弹错3-5个音、某几拍明显抢拍或拖拍。记住哪里是故意弹错的，等一下要用。

录音格式不用管，`.wav`/`.m4a`/`.mp3` 都可以（手机语音备忘录、微信录音都行）。

## 第二步：跑验证（不用打指令）

1. 打开「终端机」App，把这个 repo 的资料夹拖进去，再按 Enter（这样就切换到repo目录了，不用自己打 `cd` 路径）
2. 输入以下这一行，按 Enter（这是唯一要打的一行）：

   ```bash
   ./scripts/validate_recording.sh
   ```

3. 接下来照着画面的提示做：
   - 会看到 1-5 的歌曲选单，输入对应数字
   - 接着会要你给录音档，**直接把录音档从 Finder 拖进终端机窗口**，再按 Enter（不用自己打路径）
4. 等一下（跑评分需要几秒到几十秒），跑完**浏览器会自动打开**，直接看画面结果，不用看任何 JSON 檔案。

每次只能验证一份录音，两个版本（弹对的+故意弹错的）要跑两次这个脚本。

## 第三步：看结果

浏览器打开后会看到：

- **最上面一排分数**：总分、音准分、节奏分——分数怎么来的不用管，重点看下面的判定
- **每个音符的判定**（画面上会有钢琴卷帘图/逐音符列表）：哪些音符判定「弹对」「弹错」「没抓到」「多出来」，会用不同颜色标出来

**你要做的事**：对照你实际弹奏的内容（你自己知道弹了几个音、弹对几个、故意弹错几个），看画面上的判定跟你的认知合不合理：

- 「弹对的版本」理论上应该幾乎全部判定弹对——如果有一堆红色/判错的地方，代表算法误判了明明弹对的音，这是我们要抓的问题
- 「故意弹错的版本」应该在你故意弹错/抢拍的地方被标出来——如果完全没标出来，代表算法太宽松，没抓到

如果发现某个音符你确定弹对了、但画面判定是错的（或反过来），把「第几个音、你弹的是什么、画面判定是什么」记下来，这种案例最有参考价值。

## 第四步：回报

把这些东西一起回传（给我或负责这块的人）：

1. 录音档（两个版本都要）
2. 画面结果的截图（弹对的版本 + 弹错的版本各一张，整个画面截全）
3. 一句话说明：这首歌哪几个地方你知道自己弹错/抢拍/漏弹了

如果我还需要更细的逐音符判定数据，会在 `frontend/viewer/public/last_debug.json` 找（这个脚本每次跑完会自动存最新一次的详细结果在这里），不用你额外处理。

## 已知的限制（不是你录音的问题）

- **F5那颗键有已知的硬件特性**（基频弱、容易被误判成别的音高），如果刚好弹到 F5 判定有问题，这是已知情况，不用特别回报
- 目前的判定门槛只用一首歌调过，边界案例（画面上感觉「差一点点就判对/判错」的地方）正是我们想知道的，麻烦特别记下来

有问题随时问。
