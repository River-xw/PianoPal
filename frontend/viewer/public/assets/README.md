# PianoPal artwork

User-provided artwork used by the viewer:

- `pianopal-logo.png`: handwritten wordmark used in the global header and entry pages
- `spirit-surprised.png`: onboarding
- `spirit-greeting.png`: home navigation with a random practice quote
- `spirit-happy.png`: result feedback when the overall score is 60 or higher
- `spirit-sad.png`: result feedback when the overall score is below 60

Keep these filenames when replacing an illustration so no component changes are required.
