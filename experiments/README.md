# Experiments

Calibration scripts and exploratory tests that are useful during development but are not part of the main runtime path.

- `latency_test/`: microphone onset, latency, and rhythm validation scripts.
- `benchmarks/`: one-off hardware benchmarks (e.g. whether `basic-pitch` transcription is fast enough to run directly on the Raspberry Pi itself, not just on a laptop/cloud machine) -- see its own README for results.
